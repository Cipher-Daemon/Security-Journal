# Security-Journal
I share my stories that are worth writing to share my wins, fails and everything in between 

# Format

Each year has its own folder.

For each story in the year folder it will have the 2 number format month and the 2 number for at day followed by an underscore with the story title.

For example, if the story is "America" written on July 4th in 1776 the format would be: `1776/07-04_America.md`
